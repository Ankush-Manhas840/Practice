### 1. Best Time to Buy and Sell Stock — `sliding-window` — Easy
`id: best-time-to-buy-sell-stock`

You're given an array `prices` where `prices[i]` is the price of a stock on day `i`.
You may buy the stock on one day and sell it on a later day, at most once. Return the
maximum profit you can achieve. If no profit is possible, return `0`.

Example: `prices = [7, 1, 5, 3, 6, 4]` → `5` (buy at 1, sell at 6).

### 2. Implement a Queue Using Two Stacks — `queue` — Medium
`id: implement-queue-using-stacks`

Implement a first-in-first-out (FIFO) queue using only two stacks. Your queue class
should support:
- `push(x)` — push element `x` to the back of the queue.
- `pop()` — remove and return the element from the front of the queue.
- `peek()` — return the element at the front of the queue without removing it.
- `empty()` — return whether the queue is empty.

You may only use standard stack operations (push to top, pop from top, peek top,
check empty) on your two internal stacks.
