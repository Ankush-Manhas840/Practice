# Daily Set — 2026-07-27

No history yet, so today is 4 starter questions across different topics.
Write solutions in `solutions/<topic>/<id>.py`, then tell Claude you're done.

---

### 1. Two Sum — `arrays-hashing` — Easy
`id: two-sum`

Given an array of integers `nums` and an integer `target`, return the indices of the
two numbers that add up to `target`. Assume exactly one solution exists, and you may
not use the same element twice.

---

### 2. Valid Palindrome — `two-pointers` — Easy
`id: valid-palindrome`

Given a string `s`, determine if it is a palindrome, considering only alphanumeric
characters and ignoring case.

---

### 3. Valid Parentheses — `stack` — Easy
`id: valid-parentheses`

Given a string containing just the characters `(`, `)`, `{`, `}`, `[`, `]`, determine
if the input string is valid (every open bracket is closed by the same type, in the
correct order).

---

### 4. Binary Search — `binary-search` — Easy
`id: binary-search`

Given a sorted array of distinct integers `nums` and a `target`, return the index of
`target` if found, else `-1`. Must run in O(log n).
